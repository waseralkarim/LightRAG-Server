## LightRAG Official Deployment Design

LightRAG uses Helm templates under:

```
k8s-deploy/lightrag/
```

and specifically relies on a **Kubernetes Secret** (not a ConfigMap) to inject `.env` environment variables into the container.

---

## How Environment Variables Work

### Helm reads values from `values.yaml`

In `values.yaml`, you’ll see something like:

```yaml
env:
  REDIS_URL: "redis://redis:6379"
  NEO4J_URL: "bolt://neo4j:7687"
  MILVUS_HOST: "milvus"
  MILVUS_PORT: "19530"
  ...
```

These are then written into a `.env` file via a **Secret template**.

---

### The Secret Template (`templates/secret.yaml`)

Official file path:

```
k8s-deploy/lightrag/templates/secret.yaml
```

Content (simplified):

```yaml
apiVersion: v1
kind: Secret
metadata:
  name: {{ include "lightrag.fullname" . }}-env
  labels:
    {{- include "lightrag.labels" . | nindent 4 }}
type: Opaque
stringData:
  .env: |-
    {{- range $key, $value := .Values.env }}
    {{ $key }}={{ $value | quote }}
    {{- end }}
```

This means everything under `.Values.env` in your `values.yaml` becomes an `.env` file inside the pod at `/app/.env`.

---

### The Deployment mounts this Secret

In `templates/deployment.yaml`:

```yaml
volumeMounts:
  - name: env-file
    mountPath: /app/.env
    subPath: .env
volumes:
  - name: env-file
    secret:
      secretName: {{ include "lightrag.fullname" . }}-env
```

So, the `.env` file inside the container is automatically sourced by LightRAG.

## Deploying the Official Way

### Step 1 — Clone the repo

```bash
git clone https://github.com/HKUDS/LightRAG.git
cd LightRAG/k8s-deploy
```

### Step 2 — Modify `values.yaml` (LightRAG/k8s-deploy/lightrag/values.yaml)

Update your environment variables:

Sanitized values.yaml (safe for GitHub)
replicaCount: 1

image:
  repository: ghcr.io/hkuds/lightrag
  tag: latest
  imagePullSecrets: []

updateStrategy:
  type: Recreate

service:
  type: NodePort # Change as per as requirement
  port: 9621

resources:
  limits:
    cpu: 1000m
    memory: 2Gi
  requests:
    cpu: 500m
    memory: 1Gi

persistence:
  enabled: true
  ragStorage:
    size: 10Gi
  inputs:
    size: 5Gi

envFrom:
  configmaps: []
  secrets: []

env:
  AUTH_ACCOUNTS: 'user1:password1,user2:password2' # masked for GitHub
  HOST: "0.0.0.0"
  PORT: 9621
  WEBUI_TITLE: Onnorokom Projukti Limited
  WEBUI_DESCRIPTION: Distributed LightRAG with Redis, Neo4j, Milvus

  # LLM / Embedding Setup
  LLM_BINDING: openai
  LLM_MODEL: gpt-4o-mini
  LLM_BINDING_HOST:
  LLM_BINDING_API_KEY: "<your_openai_api_key>"

  EMBEDDING_BINDING: openai
  EMBEDDING_MODEL: text-embedding-3-small
  EMBEDDING_DIM: 1536
  EMBEDDING_BINDING_API_KEY: "<your_openai_api_key>"

  # Storage Backends (using Redis + Neo4j + Milvus)
  LIGHTRAG_KV_STORAGE: RedisKVStorage
  LIGHTRAG_VECTOR_STORAGE: MilvusVectorDBStorage
  LIGHTRAG_GRAPH_STORAGE: Neo4JStorage
  LIGHTRAG_DOC_STATUS_STORAGE: RedisDocStatusStorage

  # Redis
  # REDIS_URI: redis://<host>:6379
  REDIS_URI: "redis://:<redis_password>@<redis_host>:6379"

  # Neo4j
  NEO4J_URI: "bolt://<neo4j_host>:7687"
  NEO4J_USERNAME: "<neo4j_username>"
  NEO4J_PASSWORD: "<neo4j_password>"

  # Milvus
  MILVUS_HOST: "<milvus_host>"
  MILVUS_PORT: 19530
  MILVUS_URI: "tcp://<milvus_host>:19530"

  # Postgres (optional, if used for metadata)
  POSTGRES_HOST: ""
  POSTGRES_PORT: 5432
  POSTGRES_USER: ""
  POSTGRES_PASSWORD: ""
  POSTGRES_DATABASE: ""
  POSTGRES_WORKSPACE: default

  # Optional Qdrant (unused, disabled)
  # QDRANT_URL: http://<qdrant_host>:6333
```


### Step 3 — Deploy with Helm (Run inside /LightRAG/k8s-deploy/)

```bash
helm install lightrag ./lightrag -n lightrag --create-namespace
```

### Step 4 — Verify

```bash
kubectl get pods -n lightrag
kubectl logs -f deploy/lightrag -n lightrag
```

## Validate External Connectivity

Before deploying LightRAG, from inside a test pod in your Kubernetes cluster, verify you can reach each external service:

```bash
kubectl run test-net --image=alpine:3.18 -it -- sh

# Inside pod:
apk add --no-cache redis neo4j-client curl
nc -zv redis.serverA.local 6379
nc -zv neo4j.serverB.local 7687
nc -zv milvus.serverC.local 19530

```
